DesInspect Guide

🔍 Inspect

Click Inspect to activate element selection mode. Hover over any element on the page to highlight it, then click to select it for editing. The element's CSS and HTML become editable in the side panel.

💾 Snapshot

Save a named checkpoint of all your current changes. Useful for marking a state before experimenting further — like a git commit for your browser edits.

📦 Box Model

Shows the selected element's margin, border, padding, and content dimensions — exactly like Chrome DevTools' box model diagram. Values update when you select a new element.

🧭 DOM Navigator

A vertical tree showing the selected element in context. Click any ancestor (parent), sibling, or child to re-select it. Use the ↑ ↓ ← → arrow buttons for quick keyboard-style navigation. Hover any node to highlight it on the page.

🎨 CSS / HTML Modes

CSS mode: Edit inline styles and quick-edit common properties (color, font, spacing, etc.) with live preview.
HTML mode: Edit the element's inner HTML directly. Supports tab indentation and Cmd/Ctrl+Enter to apply.

⟷ Diff

Toggle between original and modified states on the live page. All your changes flip back to the original simultaneously — great for before/after comparison. Click again to restore your edits.

📋 Changes Tab

Lists every CSS and HTML modification you've made on this page, with inline diffs showing old → new values. Each change has:

  • Select — Jump to that element
  • 👁 Preview — Toggle just that one change between original/modified
  • Revert — Permanently undo that change

Use Copy CSS Diff to export all changes as clean CSS, or Export JSON for the full changeset.

⏱ History Tab

A chronological log of every edit action. Useful for reviewing what you changed and when.

🤖 AI UX Audit Tab

Powered by Claude, this runs AI-driven accessibility and usability checks on your selected element. Requires an Anthropic API key (stored locally only).

  • Audit Selected Element — Checks WCAG contrast, font sizes, touch targets, semantic HTML, visual hierarchy, and more. Returns actionable findings with one-click CSS fixes.
  • Check Change Impact — Reviews the changes you've made and flags whether they help or hurt accessibility and usability.

Your API key is never sent anywhere except the Anthropic API. Each audit costs less than $0.01.

💡 Tips

  • All changes auto-save to IndexedDB — they survive page refreshes and browser restarts
  • Changes are scoped to the URL — edits on one page won't affect another
  • Ctrl+Z / Cmd+Z to undo, Ctrl+Shift+Z / Cmd+Shift+Z to redo (up to 100 levels)
  • Use Tab / Shift+Tab in the HTML editor to indent/outdent code
  • Hover elements in the DOM Navigator to see them highlighted on the page before selecting
